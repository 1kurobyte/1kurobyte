    keybinds (Alt stands in for Super, which browsers can't capture)
    
    
    
      
    Alt Dlauncher
    
      
    Alt Qclose the active window
    
      
    Alt Ffullscreen
    
      
    Alt ←↑→↓ / H J K Lmove focus
    
      
    Alt Shift ←→swap with the previous / next window
    
      
    Alt 1…5switch workspace
    
      
    Alt Shift 1…5move the window to a workspace
    
      
    Alt Enterterminal (TraSH)
